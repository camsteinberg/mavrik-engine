# Security

Please report a vulnerability privately, not in a public issue:

- with "Report a vulnerability" under this repository's Security tab, or
- by email to security@getmavrik.app.

This covers what is made here: the patches, the build scripts and the archives on the releases page.
A flaw in Wine, DXMT, GStreamer or another part this build only carries is best reported to that
project. Tell me as well, so I can pick up its fix.

Only the current revision gets fixes.
