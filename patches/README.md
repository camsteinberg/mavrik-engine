# Patch series

Applied in order to the pinned Wine source (`inputs.json`, `crossover-sources`). The build stops if a
patch does not apply exactly (no fuzz, no rejects). Each patch keeps its own header. A patch that
upstream ships is removed here in the change that moves the pinned source.

DXMT's patches are in [`../dxmt/patches/`](../dxmt/patches/), for revision 8, which builds DXMT from source.

## Checked and not needed

- **DXMT's hooks in the Mac driver.** DXMT looks up `macdrv_functions` in `winemac.so` first, and
  only falls back to five separate function names when that is missing. The CrossOver tree already
  exports `macdrv_functions` (`dlls/winemac.drv/d3dmetal.c`, made for D3DMetal and DXMT), and its
  layout matches what DXMT reads (v0.80, and main at 50102f994b and a148782d43). The five fallback names stay hidden, so they need no patch.
  The `winemac` gate checks both the export and the layout on every build.
- **athei/wine's loader check (revision 2's patch 0004, removed in revision 3).** Without it, every
  32-bit program was relaunched through `start.exe`. Wine's own setting `WINEARCH=wow64` does the
  same with no patch: Wine names no alternate loader in that mode, so the program runs in the
  process it starts. mavrik sets it for every Wine program it starts in a game's folder.
- **highball-engine's patches not taken** (read at afca574b, 2026-10-24, and at e497c41d16, 2026-10-26, for revision 8): 0005 (a yield after every
  auto-reset event set, for one game's freeze; it changes every MSync wake-up, with no cost measured);
  0006 (per-program command-line switches from the registry, a feature for launcher browsers mavrik
  doesn't run); 0007 (launcher browser windows in another process; upstream Wine has its own
  implementation, 1a63b0d7c4, which arrives with the next CrossOver base); 0012 (32-bit programs
  relaunched through start.exe, which `WINEARCH=wow64` already avoids here, and an opt-in x87 helper
  this engine doesn't carry); 0015 (the Core Audio I/O buffer at half a period: it was measured without
  upstream's period fix, which 0009 carries, and sets the same buffer); 0023 (the spatial mixer for
  surround beds: it conflicts with 0009 in the same stream code, so it would need a port nobody could
  check without surround hardware); 0025 (a thread pool I/O race: not yet run in the game it was made
  for, nor reviewed upstream; updated 2026-10-19 and still not run in its game at e497c41d16). 0001, 0002 and 0014 are this series' 0001, 0002 and 0010.
